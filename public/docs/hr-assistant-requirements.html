01

Overview

Employees can ask HR policy questions — leave balances, contract terms, disciplinary procedures, Ethiopian labour law clauses — and receive streaming, cited answers grounded in real company documents. A RAG (Retrieval-Augmented Generation) pipeline ensures the LLM never hallucinates outside of indexed source material. An admin panel allows HR to keep the knowledge base current without a server restart.

RAG Pipeline — Core Implementation

python — rag_pipeline.py 
# RAG retrieval + streaming pipeline
def answer_query(question: str, history: list):
    # 1. Retrieve top-4 relevant chunks from ChromaDB
    docs = vectorstore.similarity_search(question, k=4)
    context = "\n\n".join(d.page_content for d in docs)

    # 2. Build grounded prompt
    prompt = HR_SYSTEM_PROMPT.format(context=context)

    # 3. Stream response token-by-token via SSE
    for chunk in llm.stream([
        SystemMessage(content=prompt),
        *history,
        HumanMessage(content=question),
    ]):
        yield chunk.content

Constraints & Assumptions

  • Knowledge base is limited to company-uploaded documents and Ethiopian labour law references
  • LLM will not answer questions outside the HR domain (enforced via system prompt)
  • ChromaDB is self-hosted on Render — not a managed vector database service
  • OpenAI API costs scale with usage; no rate-limiting is implemented in v1
  • Chat history is client-side only (localStorage) — no server-side conversation persistence in v1
